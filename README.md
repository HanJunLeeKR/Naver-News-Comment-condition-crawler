Collect Naver news articles and comments. The feature is to collect comment status together. Comment statuses include “author deleted,” “clean bot,” “deleted for not complying with the operating policy,” and “exposed” with no action taken. If a comment has been handled, it tracks the time the comment was still active(Chae & Lee, 2026).

After downloading the IPYNB file, you just need to run the code according to the instructions provided. No separate installation file or additional files are required. Enter the collection path, collection keywords, collection period, and collection medium accurately.
