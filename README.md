Collect Naver news articles and comments. The feature is to collect comment status together. Comment statuses include “author deleted,” “clean bot,” “deleted for not complying with the operating policy,” and “exposed” with no action taken(Chae & Lee, 2026). If a comment has been handled, it tracks the time the comment was still active.

After downloading the IPYNB file, you just need to run the code according to the instructions provided. No separate installation file or additional files are required. Enter the collection path, collection keywords, collection period, and collection medium accurately.

I used the above code in Python version 3.11.8. Please contact us if there are any bugs or other areas that need improvement. hanjunleekr@hufs.ac.kr
